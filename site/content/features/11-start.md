The first release is planned as a downloadable macOS app, with no
Terminal or Python setup. Skippable **Setup guides** will cover
configuration and bringing your Rekordbox library into manadj without
writing back to it. You'll be able to rerun them from Settings.

The **Tour**, already in the app, points out controls when you first
enter an area.

## Controls {#keyboard}

Open **PERFORM**; use the keyboard, mouse, or a mapped controller. Configure controller and [audio outputs](../../install.html#controller-check) in Setup.

| Left / right | Action |
| --- | --- |
| D / K | Play/pause |
| F / J | Hold Cue |
| B / N | Toggle loop |
| [ / ] | Switch A/C or B/D focus |

Check Deck focus. **? / F1** opens the keyboard map. Typing and dialogs suppress shortcuts.

## Load {#loading}

Drag a Library track onto a Deck. Or **Tab**, browse with arrows, then **A/B/C/D** to load; C/D require four-Deck mode. **Escape** returns to Deck controls. Wait for loading.

## Mixer {#mixer}

Drag faders, EQ, filter, or crossfader. Hold **G/H** and move the mouse for left/right channel level; release to finish. If silent, check levels, crossfader assignment, kills, and audio outputs.

## Mouse jog {#mouse-jog}

Hold **T/Y** and move horizontally to jog left/right. Configure sensitivity under **Settings → Keyboard + mouse → Mouse jog**.

## Stems {#stems}

Choose **EXTRACT STEMS**, then **STEMS READY — RELOAD**. Click a part to kill/restore; **Shift-click** solos. Disabled buttons mean stems are not loaded.

## Import and browse {#importing}

1. [Scan a tracks directory](../start/index.html#tracks-directory), or drop files onto the Library in the Desktop shell.
2. Browse sidebar lists or search by text. Select a track; check title, artist, BPM, and Key. Keep its music drive connected.

## Tags and filters {#tags}

3. Click Tags to assign or remove them. Use tag management to edit Tags, Categories, and tag colors; assignments save immediately.
4. With Library keyboard focus, press **T**, search, then **Enter** to assign a Tag; **Escape** exits. Press **E**, then **1–5**, for Energy, a separate attribute.
5. Combine text, BPM, Key, Energy, and Tag filters. **ANY** matches any selected Tag; **ALL** requires every selected Tag. Clear filters if tracks disappear.

## Playlists {#playlists}

6. Choose **+ New… → Playlist**; drag tracks onto it.
7. Sort by **# / Play order**, clear filters, then drag rows to reorder. Other column sorts change only the view.

## Archive {#archive}

Right-click → **Archive track** retains audio and metadata but removes Playlist memberships. **Archived → Unarchive** does not restore those memberships.

## Setup {#setup}

1. Install manaDJ using the [install guide](../../install.html#macos); follow its [Setup steps](../../install.html#welcome) for accounts and audio.
2. On first launch, choose **Get started**. Every step is optional.
3. **Finish later** saves progress. Resume under **Settings → Help → Setup**, or choose **Run setup again**.

## Rekordbox {#rekordbox}

4. Open **Rekordbox import**, review the collection, then **Import new tracks**. **Keep my genres** imports genres as Tags.
5. If nothing appears, open Rekordbox and **Look again**. Reconnect missing music drives. Keep manaDJ open during import.

## Tracks directory {#tracks-directory}

6. **Choose folder…**, then **Save & scan folder**. In a browser, paste the full path. **Use folder without scanning** saves only the location.

Audio stays in place; existing tracks are skipped. After a connection error, use **Check progress**.

## Tours {#tour}

7. Open **? → Tours — look around** to locate controls.

## Tutorials {#tutorials}

8. Choose **? → Tutorials — learn by doing**; perform each requested action. Tutorial Library edits are real. Replay under **Settings → Help → Tutorials**.

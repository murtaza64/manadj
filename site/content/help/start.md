## Run or revisit setup {#setup}

On First run with an empty Library, choose **Get started** or **Skip setup**. The Setup sequence covers Rekordbox import, tracks directory, Cue mode, SoundCloud, Soulseek, and Controller check. Every step is optional.

**Finish later** keeps your place. Resume from the welcome screen after relaunch or **Settings → Help → Setup → Resume setup**, even if an Import has already added tracks. **Skip setup** dismisses the sequence rather than leaving it pending.

Each guide is independent. In **Settings → Help → Setup**, check **Done**, **Skipped**, or **Not started**, then choose **Start** or **Open** beside one guide. **Run setup again** replays the sequence. Skipping a replay does not undo completed configuration.

## Bring in Rekordbox {#rekordbox}

1. Open the **Rekordbox import** Setup guide, or **Sync → Rekordbox import**.
2. Review the detected collection and **What comes across**. Toggle **Keep my genres** to import Rekordbox genres as Tags in a Genre category.
3. Click **Import new tracks** with the displayed count, or **Fill in missing library details** when tracks are already present.
4. Keep manadj open. **Continue setup while importing** lets you move on while the Import runs.

Audio stays in place and Rekordbox stays untouched. Available Hot Cues, Beatgrids, keys, MyTags, and Playlists come across; the first memory cue becomes the Main cue. Smart playlists become ordinary Playlist snapshots. Missing audio, streaming-only tracks, and saved loops are not imported. Existing manadj values are preserved.

If nothing is detected, open Rekordbox with your collection and click **Look again**. Connect your music drive if the preview reports missing audio.

## Choose a tracks directory {#tracks-directory}

1. Open the **Tracks directory** Setup guide.
2. Use **Choose folder…** in the Desktop shell, or paste the full folder path in a browser.
3. Choose **Save & scan folder** to import new audio from that folder and its subfolders, or **Use folder without scanning** to save only the location.

Existing tracks are skipped; audio is not moved. Acquisition downloads also go here. Change the location later in **Settings → Library**. A queued Scan may be waiting for other Library work; use **Check progress** after a connection error instead of starting another.

## Replay a Tour {#tour}

Click the top-bar **?** and choose a section under **Tours — look around**. Tours point out controls without editing the Library. **Settings → Help → Tour → Reset tour progress** restores first-visit Tours.

## Try a Tutorial {#tutorials}

Choose a lesson from **? → Tutorials — learn by doing**, or **Replay** under **Settings → Help → Tutorials**. Perform each requested action to advance. Tutorials are skippable, but their Library edits are real, including saved Hot Cues and Transitions.

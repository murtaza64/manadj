# g07-crt

Candidate: g07-crt   Kind: novel
Parents: none (human ask: "a crt effect would be cool").
Focus: reactivity, dramatic kicks/drops, contrast, movement.
Falsifiable question: does a CRT presentation layer (scanlines,
phosphor, glitch grammar) give abstract content a beloved identity of
its own?
Concept: an old broadcast monitor showing a sequence of abstract
"programs". The CRT pipeline is the star: visible scanlines, phosphor
RGB triad texture, slight barrel distortion, corner vignette, subtle
horizontal jitter, beam-glow bloom on bright content. CONTENT inside
the tube = simple bold field per program (interference plasma, rolling
color bars gone feral, tuned-static aurora, raster starburst) — bright,
saturated, high-contrast, always moving with mids/highs. REACTIVITY:
kick = beam SLAM (the raster brightens as one solid pulse, barrel
distortion pumps ~2%, one-frame scanline thickening — localized glow,
not a full-field white flash; respect the photosensitivity floor with
smooth sub-3Hz envelopes); snare = a one-line horizontal TEAR that
heals (mid/high gated); bass level = vertical hold tension (frame sags
under heavy bass and snaps taut); buildup = VHS tracking stress —
picture strains, chroma bleeds, noise band creeps up from the bottom
(vivid, never dim); DROP = CHANNEL CHANGE: glitch burst (one frame of
static + retrace line) into a NEW program with a new palette — the
biggest visual event the preset owns, sustained intensity on
max(drop, energy). Section boundary = channel change too (drop-triggered
changes take priority). Phrase advances program internal evolution.
Assigned tech: impulses+bands (primary), ladder tiers (channel/program
schedule), trend split, trackId genome picks the channel lineup.
Anti-resemblance: no oscilloscope content, no dust; the tube look must
read instantly (someone should say "CRT" in one second).

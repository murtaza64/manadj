Instruction: a COLOR ORGAN: 24 flowing luminous ribbons/streams cross
the frame diagonally, one per spectral band, ordered by frequency, each
permanently owning its hue (hue wheel across the 24). Band loudness =
that ribbon's width + luminosity + flow speed (quiet ribbon = thin dark
thread; loud = broad blazing current). The frame IS the spectrum — a
musician could read the mix off it. Kick = a solid transverse pressure
wave bending ALL ribbons (one physical event); snare = the loudest
mid/high ribbon whips; beat = a faint tick races along the downbeat
ribbon. Phrase = ribbon weave pattern shifts (hard cut, quantized);
section = the hue wheel ROTATES one notch (all ribbons recolor —
palette swap as spectacle). Drop = ribbons braid into one broad
full-spectrum river riding max(drop, energy); buildup = ribbons tauten
+ compress toward the diagonal. Dark floor, saturated ribbons, no dust,
non-centered. Contraction rule applies.

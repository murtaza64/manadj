# g11-shadow

Candidate: g11-shadow   Kind: novel (new PULSE representation: LIGHT +
SHADOW)
Concept: a field of simple standing monoliths/pillars (genome layout,
flat-ish shading) lit by ONE strong light source. THE LIGHT IS THE
PULSE: kick = the light JUMPS to a new position (hard cut — every
shadow in the scene snaps to a new angle; the room "changes" with each
kick without any object moving); bass level = light HEIGHT (heavy bass
= low raking light with long dramatic shadows; light bass = overhead
neutral). Mids = the monoliths sway/lean slowly (bandsSlow, palette
color on lit faces). Highs = thin rim-light shimmer on shadow edges.
Drop = the light strobe-walks around the scene in beat-locked jumps
(each jump on a beat — <=2 jumps/sec luminance-safe since shadows swap
direction but total luminance stays near-constant), riding max(drop,
energy); buildup = the light slowly descends (shadows grow — dread).
Section = new monolith layout + palette. Shadows must be crisp and
legible — the preset reads as LIGHT CHOREOGRAPHY.
Standing law: docs/visualizer-ga.md — taste calibration, hard safety, dust fatigue, feedback contraction (cap whole-field grades < 1), MOTION SMOOTHNESS (velocity rides frame.bandsSlow ?? frame.bands; instantaneous bands/impulse only for punches/pops).

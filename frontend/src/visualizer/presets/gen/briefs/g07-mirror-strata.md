# g07-mirror-strata

Candidate: g07-mirror-strata   Kind: novel (mirror-ladder style)
Parents: g02-mirror-ladder (1016, 4 approvals) — style parent only.
Human ask: "more mirror-ladder style ideas"; "metric evolution/change".
Falsifiable question: can the ENTIRE metric hierarchy be staged at once
— each tier owning a visual stratum that changes ONLY on its own
boundary — and stay legible rather than chaotic?
Instruction: a mirrored composition of four nested strata, each owned
by one metric tier, each changing with a HARD CUT exactly on its
boundary and holding steady between:
- BEAT stratum (innermost, fastest): a small mirrored kernel that
  re-poses every beat (pose from beat index mod small cycle).
- BAR stratum: a mid-scale mirrored frame that re-shapes every bar
  (`beat.ladderBarIndex ?? beat.barIndex`).
- PHRASE stratum: the dominant scene geometry — symmetry count,
  palette bank, and layout snap every 4 bars.
- SECTION stratum (outermost, slowest): the world container — background
  regime, mirror axis orientation, overall color temperature — cuts
  every 16 bars (the biggest visual event short of a drop).
Nesting must read: strata are spatially nested (kernel inside frame
inside scene inside world) so the eye learns which scale moves when.
Kick = the beat kernel strikes the bar frame (solid impact, light
transfers outward one stratum); snare = glint ripple across the phrase
stratum's mirror seams. Drop = ALL strata cut simultaneously to their
next state + sustained cross-strata light flow (rides max(drop,
energy)) — the hierarchy briefly moves as one. Buildup = inner strata
accelerate their internal motion while cuts stay on-grid (tension
between urgency and quantization).
Contrast/movement: dark stage, strata carry saturated light; between
cuts everything still MOVES continuously (rotation/flow within each
stratum) — cuts change STATE, motion never stops.
Assigned tech: full ladder hierarchy + beat phase (primary), impulses,
genome (stratum vocabularies), trend.
Anti-resemblance: not a mandala (mirror symmetry yes, radial repetition
no); no dust.

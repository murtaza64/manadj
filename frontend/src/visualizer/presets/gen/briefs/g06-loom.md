# g06-loom

Candidate: g06-loom   Kind: novel (sol-review concept "Kinetic Loom")
Parents: none (concept from
handoffs/2026-08-18-gpt56sol-viz-review.md §Kinetic Loom).
Human ask: non-circular-center layouts.
Falsifiable question: does carrying band identity through THREAD
GEOMETRY (thickness/tension/curvature) read more musically than
brightness-mapped spectrum bars ever did (bars/spectrum are fossils)?
Concept: the 24 spectrum bands are warp threads crossing three broad
low/mid/high weft families spanning the frame. Lows = thick load-bearing
cords, mids = ribbons, highs = hairline filaments; all sample a wide
traveling palette. Spectrum values change TENSION and CURVATURE, not
merely brightness. Kick = one solid yank of the loom frame + a
compression kink traveling down the cords; snare/hat shed mid/high
fibers only. Each phrase weaves a recognizable motif (song-genome
seeded), denser and more knotted toward the boundary. Buildup pulls the
fabric taut while color races along it; drop releases a large persistent
fold riding max(drop, energy). Sections change weave topology: plain,
twill, braid, open mesh.
Invariants: band identity = thread class; geometry response beats
luminance response; stage dark enough for thread hierarchy but never
still.
Degrees of freedom: motif vocabulary, thread rendering (SDF lines vs
textured strips), fold mechanics.
Assigned tech: 24-band spectrum (primary), impulses, phrase tiers via
`beat.ladderBarIndex ?? beat.barIndex`, trackId genome for motifs.
Anti-resemblance: no centered radial glow, no starfield/dust medium, no
tunnel; horizontal/diagonal composition, not concentric.

Baseline: personal `murtaza64/manadj` main at `d137e2d7` (piracy-removal merge). This map uses current source modules, not only the older Android README's pending labels. It is not approval to remove or defer Android features permanently.

## Apple runtime checkpoint

At `24bb9012`, unsigned simulator and arm64 device-SDK builds passed. Seven native and three UI tests passed with zero failures or skips on regular iPhone 16 / iOS 18.5. [Run](https://github.com/murtaza64/manadj/actions/runs/44484532224), [evidence](https://github.com/murtaza64/manadj/actions/runs/44484532224/artifacts/14511085536). These are synthetic-fixture simulator checks, not physical-device or complete Android-parity acceptance. Both PR merges remain held.

## Status key

- **Host-tested**: relevant Swift/C bridge behavior ran on Linux. Not iOS runtime proof.
- **Source only**: implementation exists, but Apple build/runtime validation is missing.
- **Core only**: model/engine behavior is available, but the iOS application does not expose the complete feature.
- **Missing**: not implemented in this slice. It remains an Android-parity gap.

## Tonight live-play v0 scope, November18 owner clarification

Session playback and recording may stay under construction. Current priority is direct local-Wi-Fi library transfer from the already-populated laptop, then loading and playing downloaded tracks on the iPhone. This does not authorize cloud relay, library upload, new company-account access or unrelated work-laptop installation. The iOS sync source uses one explicitly entered desktop origin and rejects redirects. Existing fixture HTTP tests are not proof of the real desktop listener or physical LAN access. Real composed-server and native common-codec tests are being added; physical iPhone pairing/network permission, Wi-Fi transfer and audible playback remain separate acceptance checks. Only the laptop's present files can transfer; absent originals must not be advertised as downloaded. The code does not implement audio transcoding for unsupported formats.

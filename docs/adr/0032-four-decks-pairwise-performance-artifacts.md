# Four Decks, pairwise performance artifacts

manadj has four fixed app-owned Decks, A–D, but Transitions and Cameos remain strictly pairwise role-addressed artifacts. A multi-Deck move is overlapping pairwise evidence on a shared capture-session clock, grouped by engagement; this preserves reusable pair knowledge and avoids n-ary automation whose alignments and competing lane values need arbitrary conflict rules. The Conductor and editor map pairwise roles onto physical Decks rather than persisting Deck identity in artifacts.
